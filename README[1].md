# Digital Service App

A responsive Marathi-first starter web app for digital service tools.

## Current working features
- Responsive home page and service catalogue
- Search and category filters
- Residence self-declaration draft form
- Live document preview
- Browser print / Save as PDF
- PWA manifest and service worker starter

## Important
This is an initial front-end version. Services marked "लवकरच" are placeholders and are not yet implemented. Government links open official portals; the app does not claim to issue government certificates or approvals. The residence declaration is a draft template and should be checked against the applicable official format before use.

## Cloudflare Pages
For a static Pages deployment, use the repository root as the build output directory and leave the build command blank. No framework is required.
